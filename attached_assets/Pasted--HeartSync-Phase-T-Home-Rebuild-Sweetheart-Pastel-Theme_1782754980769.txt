## Phase U — "Sweetheart" theme: claymorphism tokens (a second full theme, not a replacement)

```
Build this as a complete second theme using the existing ThemeExtension architecture —
selectable from the Theme picker alongside Midnight Rose, which stays exactly as built.

Tokens:
- Background: soft gradient, Lavender Mist #F3EFFF to Blush Mist #FDEEF6
- Card surface: Cloud White #FFFBFE with a soft colored "puffy" shadow (light purple-
  tinted, blur ~24, low opacity) instead of a flat grey shadow — this is what creates the
  claymorphism look in your references.
- Primary accent: Lavender Pop #9B87F5
- Secondary accent: Coral Blush #FF9EB5
- Icon-badge accents (one flat pastel color per badge, white icon inside, ~40x40,
  rounded-square — copy this exact pattern from the dashboard reference's Songs Played /
  Favorites / Hours / Streak cards): Sunshine Yellow #FFD66B, Sky Mint #8CE0C9, Soft Peach
  #FFC9A8
- Text: Plum Ink #4A3B6B on light surfaces — soft dark, never pure black

Typography for this theme only: Quicksand or Baloo 2 for headers, Nunito for body —
rounded, friendly letterforms, replacing Midnight Rose's elegant serif entirely when this
theme is active (swap the font role, not just the color).

Shape language: 24-28px corner radius everywhere, pill-shaped buttons, the icon-badge
pattern above used consistently on every stat/feature card: small colored badge, big
number, small label underneath — exactly the dashboard reference's layout.

Asset note: the couple/character illustrations in your references are rendered 3D art,
not buildable with Flutter widgets. Source a small matching set of 3D-clay-style couple
illustrations (a few poses/expressions — welcoming, celebrating, comforting) from an
illustration marketplace or commissioned artist, used as static image or Lottie assets
for the login hero and key empty states. Everything else — shadows, rounded corners,
gradients — is native Flutter, no assets needed.
```
