## Phase N — Atmosphere foundation (build this first — biggest visual impact, least complexity)

```
Refine the existing "Midnight Rose" theme tokens with these more precise values (same
concept, tighter palette) and build the time-based sky system for Chat specifically:

Tokens:
- Midnight Purple #1B1836 — chat background base
- Rose Gold #E8A598 — primary warm accent
- Soft Lavender #A78BFA — tertiary accent, used for the "Missing You" mood state
- Champagne Gold #F3C98B — premium/special-moment accent
- Moon White #F8F6F2 — text on dark surfaces

Dynamic Love Sky: the Chat screen's background shifts by time of day, checked once on
screen load and re-checked every 15 minutes (not continuously):
- Morning (5am-11am): soft peach gradient, a few slow-drifting bird-silhouette particles
- Day (11am-5pm): keep it calm and quiet — this is the one window with NO extra
  background motion, so the effect doesn't become wallpaper noise by midday
- Evening (5pm-9pm): golden-orange gradient, slow-drifting petal particles
- Night (9pm-5am): Midnight Purple gradient, star field, slow-moving cloud silhouettes

Heartbeat glow: reuse the existing HeartbeatPulse wrapper from the design system phase,
applied to a full-screen radial glow at very low opacity (5-8%) behind the message list
— a 4-second double-beat cycle, barely perceptible, not a visible pulsing shape.

Cap rule for this phase: only ONE ambient particle system active at a time on this
screen (birds OR petals OR stars — never combined), and Day mode has none at all. This
is your performance budget — everything added in later phases has to fit inside it, not
stack on top of it.
```

## Phase P — Mood Atmosphere (unify Aura + Weather + Candle Mode into one controller)

```
Relationship Aura, Emotional Weather, and Candle Mode are three visual expressions of
data you already have — don't build three separate listeners. Build one
MoodAtmosphereController that reads the existing mood field (from Phase 1) plus the
current time, and outputs one state object: { auraColors, weatherParticle, warmthLevel }.

Mapping:
- Happy -> Pink + Champagne Gold aura, no weather particle
- Romantic -> Rose Gold + Soft Lavender aura, occasional petal drift
- Missing You -> Soft Lavender + Midnight Purple aura, light rain particle, slowed pace
- Excited -> Champagne Gold aura, sparkle particle

Candle Mode is a time-bracket addition, not a separate system: after 10pm, whatever aura
is active gets a warm amber overlay and the particle (if any) shifts to a slow candle-
flicker effect instead of its daytime look — same controller, one more conditional.

Same cap rule as Phase N: this mood particle is the ONE ambient system allowed at a
time — it doesn't run alongside the Dynamic Love Sky's own particle, it replaces it when
active. Build a simple priority order (mood particle overrides time-of-day particle when
a strong mood is set) instead of layering both.
```
